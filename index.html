Architectural Principles

Zero compromise clipboard.

Designed for programmers, writers, and security-minded professionals who refuse to let clipboard data touch third-party servers.

01 / LOCAL-FIRST ON-DEVICE

100% Air-Gapped Security

Zero outbound network requests. Passwords, API tokens, sensitive credentials, and private client snippets are encrypted into an on-device local database and never leave your Mac.

Zero Telemetry · No Cloud Relays
02 / CLASSIFIER SYNTAX AST

Smart Code & Format Detection

Automatically detects and tags code snippets (Swift, Python, JS, SQL), color hex values, links, and formatted plain text with natural language prose filtering.

AST Validation · Zero False Positives
03 / SEARCH FUZZY RECALL

Instant Keyboard Recall

Summon with global hotkey (⌘⇧V). Type any partial word to fuzzy-filter thousands of historical clips instantly, then hit ⌘1-9 or Enter to paste immediately.

Sub-10ms Lookup · Fuzzy Search Engine
04 / PERFORMANCE < 15MB RAM

Native Swift & CoreData

Unlike heavy 300MB Electron clipboard managers, ClipLocal is a lightweight menu bar app built directly with Swift and AppKit. Uses virtually zero CPU cycles in background.

Zero Daemon Lag · Minimal Battery Draw
05 / UI FROSTED GLASS

Continuous Curve HUD

Native macOS frosted glass material with continuous corner curves and SF Symbol icons. Clean popover positioning that never obscures active editor windows.

Apple Human Interface Guidelines Compliant
06 / DISTRIBUTION HOMEBREW & DMG

Universal Fat Binary

Native compilation for Apple Silicon M1/M2/M3/M4 and Intel Macs. Verified distribution via official Homebrew tap and automated zero-metadata GitHub releases.

brew install cliplocal · Fat Mach-O
